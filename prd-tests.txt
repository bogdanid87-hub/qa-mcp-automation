# test_name: ip-geolocation-prepopulates-shipping-estimate
# spec_file: tests/ui/cart-shipping-estimator.spec.ts
# page_paths: /view_cart
# source: direct
# risk: critical
# priority: critical
# reason: Shipping cost pre-population directly affects the cart total a user sees before checkout, making it a revenue-critical display.

1. Add a product to the cart and navigate to /view_cart.
2. Wait for the shipping estimator widget to render on the cart page.
3. Assert that the postal/zip code input field is pre-populated with a value (non-empty) derived from IP geo-location — do not assert a specific code, just that auto-fill occurred.
4. Assert that an estimated shipping cost figure is displayed in the estimator section (e.g. a element containing a currency symbol and a numeric value).
5. Assert that the cart total shown in the estimator reflects the product subtotal plus the pre-populated shipping estimate.

# spec_file: tests/ui/cart-shipping-estimator.spec.ts

7. Assert that the postal code field retains the manually entered value after recalculation.
